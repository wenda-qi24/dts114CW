# Freudian Dream Interpreter | AI-DLC Full Lifecycle Project
The project is developed strictly under the AI-DLC three-phase development flow (Inception / Construction / Operation), and run via sequential Jupyter notebook cells. The execution purpose is described below.

## Key Description
1. Due to the relatively complex content of the designed website, it is difficult to ensure that the code generated by the prompt can run both front-end and back-end every time, so some hard coding is used to ensure the functionality of the output.  

2. You may have noticed that there is an apikey in my .env file, but this is just an example and is not usable. You need to use your own API.

3. The API key you provide needs to meet the requirements and must have the ability to generate images, because the part of the website that generates images will use the API to create an illustration. Therefore, please ensure that your API has the image generation function; otherwise, this part will fail.

## Key Operation Instructions

### Some important instructions that need to be considered for operation
1. In the parts before phase 3, you need to run them sequentially, because the generation of each step is based on the results generated above, so please do not change the order or skip any cell.

2. In Section 3.1, if you want to complete the deployment of Docker, please run the code first, and then follow the output results to perform manual operations in order to complete the deployment.

3. When you execute step 4, a CICD YAML file will be automatically generated, which is currently fixed, and a test file will also be output. If you want to run the test, please go to the location of the app_test.py file and enter the command pytest -v in the terminal.

## Attention

### In order to ensure that the results can be fully reproduced using only one .ipynb file, the required yml file and test file will be generated after executing the last cell, although they are not explicitly provided. However, these files and successfully generated examples are provided in the GitHub and CW uploads, and they can be used directly by copying and connecting to the correct API.
